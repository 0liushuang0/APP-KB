### 2.3 AI 相关数据（部分上传）

| 数据类型 | 存储位置 | 是否上传 | 说明 |
|---------|---------|---------|------|
| AI 调用日志 | SQLite `ai_call_logs` 表 | ❌ 元数据不上传 | 记录模块/耗时/Token |

### 2.4 备份数据（100% 本地）

| 数据类型 | 存储位置 | 格式 |
|---------|---------|------|

## 三、数据传输路径

### 3.1 本地通信（无网络）

```
浏览器 (:5174) ──Vite代理──→ 后端 (:3001) ──HTTP──→ AI服务 (:8000)
     │                         │                        │
     │                         │                        │
     ▼                         ▼                        ▼
 localStorage            SQLite app.db           FAISS vectors.db
 (AI对话历史)            (业务数据)              (向量索引)
```

### 3.2 云端 AI 调用（用户主动触发）

```
用户提问
    │
    ▼
AI服务：本地检索（FAISS）
    │
    ├─ 检索到相关片段
    │      │
    │      ▼
    │  egress.assert_allowed() ← 检查是否允许出网
    │      │
    │      ├─ local_only 模式 → 拒绝出网 → 降级到本地模型
    │      │
    │      └─ cloud 模式 → 继续
    │              │
    │              ▼
    │         egress.sanitize_messages() ← PII 脱敏
    │              │  （自动隐藏手机号/身份证/邮箱/银行账号）
    │              │  （自定义敏感词替换）
    │              ▼
    │         HTTPS POST → 云端 API
    │              │
    │              ▼
    │         egress.record() ← 记录出境台账
    │              │
    │              ▼
    │         返回 AI 回答 → 本地展示
    │
    └─ 未检索到 → 返回"知识库中未找到"
```

### 3.3 数据出境控制

| 模式 | 行为 | 配置方式 |
|------|------|---------|
| `cloud`（默认） | 允许调用云端 AI，自动脱敏 | `EGRESS_MODE=cloud` |
| `local_only` | 禁止一切出网，仅用本地模型 | `EGRESS_MODE=local_only` |

## 四、数据安全措施

### 4.1 传输安全

| 环节 | 措施 |
|------|------|
| 前端→后端 | httpOnly Cookie + SameSite=Lax（同源） |
| 后端→AI服务 | 内部 HTTP（本地通信） |
| AI服务→云端 | HTTPS/TLS 1.2+（外部通信） |

### 4.2 存储安全

| 数据 | 措施 |
|------|------|
| API Key | AES-256-GCM 加密（机器特征派生密钥） |
| 用户密码 | bcrypt 哈希（salt=10） |
| JWT 令牌 | httpOnly Cookie（JS 不可读） |
| 上传文件 | 路径穿越防护（safeUploadTarget） |
| 数据库 | SQLite 文件权限（仅当前用户） |

### 4.3 脱敏规则

自动检测并替换：
- 手机号：`1[3-9]\d{9}` → `[手机号已隐去]`
- 固话：`0\d{2,3}-?\d{7,8}` → `[固话已隐去]`
- 邮箱：`[\w.+-]+@[\w-]+\.[\w.-]+` → `[邮箱已隐去]`
- 身份证：`\d{17}[\dXx]` → `[身份证已隐去]`
- 银行账号：`\d{16,19}` → `[银行账号已隐去]`
- 自定义敏感词：用户配置 → `[敏感词N]`

## 五、用户数据权利

| 权利 | 实现方式 | 入口 |
|------|---------|------|
| 数据导出 | JSON 全量导出（34 张表） | 设置→备份还原→导出 JSON |
| 数据删除 | 删除本地数据库 + 向量索引 | 手动删除 data/ 目录 |
| 云端数据删除 | 删除向量索引中的文档片段 | 文档管理→删除文档 |
| AI 功能关闭 | `EGRESS_MODE=local_only` | .env 配置 |
| 出境记录查看 | `egress.log` 文件 | 设置→AI配置→出境台账 |
| 备份下载 | ZIP 下载 | 设置→备份还原→下载 |
