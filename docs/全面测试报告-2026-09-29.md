## 三、发现的 Bug

### BUG-001：客户搜索关键词含特殊字符返回 500（P2 级）——**已修复**

**现象**：搜索关键词含单引号等 SQL 特殊字符时，接口返回 500。

**根因**：`customers.service.ts` 的联系人子查询中 `cp.customerId` 未加双引号——PostgreSQL 将未引号标识符折叠为小写 `customerid`，与实际列名 `"customerId"` 不匹配（SQLite 大小写不敏感故未暴露）。

**修复**：`cp.customerId` → `cp."customerId"`。重建后复测：**所有特殊字符关键词（含完整 SQL 注入语句）全部返回 200**，数据库表完好。

**其余 3 个"失败"均为测试脚本的 urllib Cookie/URL 编码与 curl 行为差异**，同一请求 curl 验证全部通过。

**系统级 Bug 数：修复后 0 个。**
