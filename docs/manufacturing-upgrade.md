# 离散制造业务协同升级说明

## 本轮已接入

- 在“客户业务 → 制造业务协同”按成套/非标装备、重复零部件、备件维修技改、研制验证四种业务类型建售前项目；每种类型使用独立阶段路径与评审部门清单。
- 将客户、需求、报价、合同、执行项目串联。进入“已签约”前核对已审批报价、签订日期、合同审批状态和报价归属；进入“交付中”前必须关联执行项目。
- 登记客户设备档案、逐条技术符合性、跨部门评审、工程变更和交付里程碑；评审、结项有阻断规则。
- 项目参与人员显式分配；多人编辑售前项目通过版本号拒绝旧版本覆盖；统计业务类型数量、逾期行动并可导出 CSV。
- 未签约商机可登记失单原因并结案，报表区分完成与失单数量。

## 团队部署前配置

1. 运行数据库迁移并备份现有数据库；团队模式优先 PostgreSQL。迁移文件为 `1788700000000-AddManufacturingWorkflow.ts`。
2. 在部门管理中配置所需标准代码：`sales`（营销）、`engineering`（技术）、`production`（生产）、`procurement`（采购）、`quality`（质量）、`finance`（财务）、`service`（售后）。评审人须拥有审批角色、加入项目，并属于对应代码的部门；系统管理员可代办。
3. 创建报价、合同和执行项目时保持同一客户与正确的合同/报价关联。合同需完成内部审批并填写真实签订日期。

## 尚待继续完善的商用范围

- 现有成本/报价模块还需面向 BOM、工序、外协、工装、运费、税费及毛利底线形成版本化成本模型；当前制造协同仅关联已有报价。
- 交付里程碑目前由人工更新，尚未与 ERP、MES、PLM 或售后工单做可靠同步和冲突处理。
- 工程变更已有客户确认依据字段及审批关口，尚需多部门影响评估、合同补充协议和成本/交期自动回算。
- 项目清单页面只载入最近 500 条；报表包含当前用户全部可见记录。企业级统计仍需服务器端筛选、分页、快照、口径定义及导出审计。
- AI 尚未接入图纸密级、版本有效性、客户隔离与人工复核工作流；不能把模型输出直接当作技术批准或承诺交期。
- 当前只覆盖核心业务规则的自动化测试及构建验证；上线前还需完整端到端演练、迁移回滚演练、并发与权限渗透测试、备份恢复和内网客户端验收。
