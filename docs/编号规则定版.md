## 二、核对清单（与纸面习惯对齐，逐项打勾）

- [ ] ① 合同编号年份位数：现行 4 位（CON-2026-001）。若贵司合同台账习惯 2 位年（CON-26-001），在系统设置改 `contract.yearFormat = YY`。
- [ ] ② 售后工单前缀：现行 TIC + 4 位年。若纸面用"售后-"或"服-"等中文前缀体系，需确认是否沿用字母前缀。
- [ ] ③ 标准方案前缀 SOL 与技术文档编号（如企标号）是否冲突。
- [ ] ④ 物料 MAT 4 位流水是否与 ERP 物料编码对齐（后续 ERP 集成立项时以 ERP 编码为准，本系统编号做映射）。
- [ ] ⑤ CST 客户前缀 2 位年已按贵司习惯采用（原默认 CUST-2026-001）✓ 已定制。

## 三、修改入口与注意事项

- **入口**：系统设置 → 编号规则（存储于 `system_configs.numbering.rules`，只覆盖显式配置的项，未配置项走代码默认值）。
- **修改即时生效**，只影响**新建**单据，历史编号一律不动（尾号继承按各单据实际编号取尾，不重算）。
- **流水取当前最大序号 +1**：删除单据后新建会跳号（不重号），重号比跳号严重，此为正确取舍。
- 修改前**先备份**（备份恢复见管理员手册）。
