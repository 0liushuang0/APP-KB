## 一、一票否决项检查（7 项）

| 否决项 | 框架标准 | 实测状态 | 判定 |
|---|---|---|---|
| 身份认证 | SSO(SSO/LDAP/OIDC) + MFA | 仅账号密码 + JWT 轮换（httpOnly Cookie、刷新令牌一次性 + 重用检测）；**无 SSO、无 MFA** | ❌ 不达标 |
| 数据隔离 | 租户/部门数据完全隔离 | 单租户；部门/角色/分组/私有五档 visibility + 行级权限下沉 SQL + 项目成员三档授权，team 模式实测越权 400 | ⚠️ 部门级达标，租户级 N/A |
| 数据备份 | 异地备份 + RPO<1h + RTO<30min | 本地 pg_dump 每 6h 自动保 7 份 + 手动备份 + 附件归档（实测成功）；**RPO=6h、无异地、RTO 未演练** | ❌ 不达标 |
| 传输加密 | 全链路 TLS 1.2+，AI 请求 TLS 1.3 | 内网 HTTP 部署；代码已支持 COOKIE_SECURE/HTTPS 开关但 nginx 未配 TLS | ❌ 不达标 |
| 审计日志 | 全操作审计保留 ≥180 天 | AuditLogInterceptor 全操作审计 + AI 调用/出境台账（实测）；**保留策略未配置，无防篡改** | ❌ 不达标（有审计无保留） |
| 合规底线 | 等保二级+ / PIPL | PIPL 部分符合（本地处理、出境脱敏+阻断、隐私政策+首次同意、数据可删除/导出）；**等保未定级备案** | ⚠️ 部分达标 |
| 功能验收 | 附录 P0 用例 100% | 此前评估的 P0 验收清单 8 条中 6 条 API 级实测通过（越权/审批一致/防覆盖/改单重审/进度联动/AI 降级），断电自启与 pg_restore 演练待做 | ⚠️ 基本达标 |

**否决结论：4 项硬性不达标（SSO+MFA、异地备份、全链路 TLS、审计保留）。按框架规则，综合分无论高低均为"不推荐商用"（企业级口径），须整改后复测。**

### 校准口径（按系统真实定位：≤50 人内网单租户）

将"规模性基础设施"类失分项（K8s/HA/异地灾备/千级并发/APM/等保三级对外销售要件等，合计约 12 分权重）按定位差豁免后，估算综合 **76-79 分，落入"有条件商用"区间**——条件正是下节 P0 清单。两个口径的差值（约 10 分）全部来自基础设施与流程合规，**没有一分来自业务功能**：业务功能维度（内容生命周期 78、AI 76）已接近甚至达到企业标准。

### 结论要点

1. **业务内核强、企业外壳弱**：全链路业务（含本迭代补齐的审批闭环/版本冻结/回款台账/成员授权/商机漏斗）完整且经多账号实测；短板集中在框架第七、九、六章（安全合规 60、部署运维 47、数据库 64）——即"运维与合规工程"而非"产品功能"。
2. **四个否决项是真实阻断**：TLS、异地备份+RPO/RTO、审计保留、MFA。内网小团队场景下它们不改变日常使用，但按任何商用框架都是必须补的课，且成本可控（见建议 1-4）。
3. **两处框架硬要求完全未做**：AI 固定评测集（准确率/幻觉率无基线）与性能量化实测（Web Vitals/P99 压测）——框架明确"未实测最多 0.5 分"，这是失分放大器。
4. **超框架能力**（框架未要求但已实现）：数据出境三档管控+台账、报价版本冻结+乐观锁防覆盖、审批中心与单据状态一致性、双方言迁移链、应收台账——在"知识库类产品"假设之上多做了"业务闭环"一层。

## 四、优化建议（分级排序）

### P0 — 一票否决消除（商用前必须，预计 1-2 周）

1. **全链路 TLS**：nginx 配内网证书（自建 CA 或企业证书），HTTP→301→HTTPS；`COOKIE_SECURE` 恢复默认开启；AI 出站请求验证 TLS1.3。*验收：浏览器锁标志 + 抓包验证。*
2. **备份达标**：WAL 归档（pg_basebackup 每日全量 + WAL 连续归档，RPO→分钟级）；备份定时复制到第二台设备/网络盘（异地要件）；备份包 AES 加密；做一次完整恢复演练并记录 RTO 实测值。*验收：RPO<1h、RTO<30min 书面证据。*
3. **审计保留与防篡改**：审计表按月归档 + 保留 ≥180 天策略；PG 层 REVOKE UPDATE/DELETE ON audit_logs（只追加）；登录日志独立留存。
4. **MFA（TOTP）**：otplib 实现管理员 TOTP 绑定+登录第二因素；SSO 视企业是否有 AD/LDAP 再定（无则可后置并在 N/A 清单登记）。

### P1 — 得分关键项（1-2 个月）

5. **可观测性**：node_exporter+postgres_exporter+Prometheus+Grafana（Compose 加两服务即可）；告警接邮件/IM（磁盘>80%、备份失败、ERROR 激增、AI 不可用）；应用日志改 JSON 结构化。
6. **AI 评测集**：建 20-50 条种子问答（覆盖各文档类型），3 人盲评取均值，产出准确率/幻觉率/引用准确率基线，纳入效能看板；此后换模型前后复测（框架复测规则）。
7. **性能实测基线**：Lighthouse（FCP/LCP/CLS/INP）+ k6 对核心接口（列表/详情/RAG 问答）压测 P99，记录测试环境；补 1366×768 与四浏览器兼容矩阵实测。
8. **CI/CD**：Gitea/GitHub Actions 流水线（lint+tsc+312 测试+构建+镜像），提交即验证——本会话多次"忘重启/忘构建"的隐患一并根治。
9. **安全扫描常态化**：npm audit + Trivy 镜像扫描进流水线；密码复杂度/历史策略；Prompt 注入基础防护（输入指令检测）与 AI 输出敏感审核接入 sanitizer。

### P2 — 体验与合规增强（视商用化进程）

10. 等保二级定级备案（若对外销售）；第三方渗透测试（每年）。
11. i18n 框架预留（react-i18next 抽离文案）、WCAG AA（对比度/键盘导航/ARIA）、Ctrl+K 全局搜索快捷键、关键操作撤销。
12. 大表格虚拟滚动、Sentry 前端 APM、对话导出/分享、仪表盘定制。

### 定量预期

P0 完成 → 解除"不推荐"，校准口径升至 ~82；P0+P1 完成 → 原口径约 74-76、校准口径 ~86，达到"有条件商用→推荐商用"门槛；P0+P1+等保 → 原口径 ~78+，可对外销售。
