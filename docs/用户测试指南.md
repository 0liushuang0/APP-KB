# 智能知识中心 · 用户测试指南

> 版本：V2.0 · 2026-09-29 · 面向参与全面测试的业务与运维人员

## 一、环境与入口

| 服务 | 地址 |
|---|---|
| 前端界面 | http://localhost:5274 |
| 后端 API | http://localhost:3101/api |
| API 文档（开发态） | http://localhost:3101/api/docs |
| AI 服务 | http://localhost:8100 |

- 启动：双击项目根目录 `run.bat`（自动清理端口并拉起三个服务，浏览器打开前端）。
- 数据库：PostgreSQL 17（本机 5432，库名 aikb）。备份：设置 → 备份还原，或每 6 小时自动备份。
- 单机模式（当前配置）：打开即自动以管理员登录；团队模式测试见第五节。

## 二、建议测试路径（按业务主线走一遍）

**1. 客户与需求（销售）**
- 客户中心：新建客户（填行业/区域/等级/业务状态），查看客户 360 视图。
- 需求管理：新建需求，重点测试新上的 **商机信息** 区——预计成交金额、预计成交日期、赢单概率、下次跟进日期；失单时填输单原因。
- 上传一份需求附件（Word/PDF），试试「AI 分析」提取结构化参数。

**2. 方案与报价（技术/报价员）**
- 从需求生成方案，编辑后提交。
- 新建/编辑报价：注意 **金额由服务器计算**（数量 × 单价，改动明细后总额自动重算）；报价修改后，此前版本可在详情「历史版本」区回看。
- 试着把某行数量 × 单价故意算错提交——保存后金额仍是正确的即通过。

**3. 审批（主管）**
- 团队模式下报价/合同需审批：审批中心通过后，回到业务页确认状态已同步变为"已批准"。
- 把一张**已审核**的报价改一下金额——它应自动退回"待审批"并生成新的审批任务。

**4. 合同与回款（商务/财务）**
- 报价列表「转合同」生成合同；登记签订日期后状态流转为已签订。
- 合同详情 → **回款台账**：按首付款/发货款/验收款/质保金登记应收节点，点「收款」登记实收金额、日期与发票号；顶部汇总条核对 应收/已收/未收/进度。
- 合同列表右上角「导出应收」→ 下载 Excel 台账给财务对账。

**5. 项目与任务（项目经理）**
- 立项后进入项目详情：**项目成员** 区添加成员（管理/成员/只读三档角色）；任务指派给真实账号（被指派人会在通知里收到）。
- 完成全部任务后，项目进度应自动变为 100%。

**6. 售后与知识库**
- 售后工单：登记→处理→关闭。
- 知识库：上传几份历史文档，等索引完成后在智能问答里问一个文档里的问题，核对**引用溯源**。

## 三、多人协作专项（重点）

两人两台电脑（或两个浏览器配置文件）同时测试：

1. **防覆盖**：A、B 同时打开同一张报价，A 先保存，B 再保存——B 应看到"该报价已被他人修改，请刷新后重试"，而不是静默覆盖。
2. **权限**：A 建一个可见性=私有的客户/项目，B 直接访问应被拒绝；B 被加为项目成员后可看可协作，调成"只读"后不能再改。
3. **通知**：给 B 指派任务 / 把 B 加入项目，B 的通知中心应收到消息。

## 四、数据安全专项

- 设置 → 备份还原：手动创建一次备份，确认 zip 生成（含数据库快照与附件）。
- 自动备份为双层级：**每小时的仅数据库备份（数据最多丢 1 小时）** + 每 6 小时全量（含附件）；产物默认 AES-256 加密（`backend/data/.backup-key` 为解密密钥，请另行抄录保管）。
- 删除任意单据 → 回收站还原。
- 审计日志：查看上述操作的留痕（数据库层已做只追加保护，任何人无法修改历史审计）。

## 四点五、双因素与 HTTPS（新增）

- **双因素认证**：设置 → 安全设置 → 开始绑定 → 认证器 App 手动输入密钥 → 输入 6 位码启用。启用后登录需密码 + 动态码。建议管理员必测。
- **HTTPS 入口**（正式内网形态）：`node scripts/https-proxy.mjs` 后访问 `https://服务器IP:8443`；证书生成与员工机信任导入见 docs/备份与恢复.md。测试时可验证地址栏锁标志与登录正常。

## 五、团队模式试点（可选）

在 `.env` 把 `APP_MODE=single` 改为 `team` 后重启后端：
- 首次启动会自动创建管理员 `admin`（密码打印在 `logs\backend.log`，**首次登录后立即修改**）。
- 管理员在设置里创建各角色账号（销售/技术/审批员等），分发后按第二、三节路径多人测试。

## 六、已知边界（测试时不必报障）

- 断网时 AI 功能降级到本地模型或暂不可用，但客户/报价/项目等基础业务不受影响。
- PostgreSQL 模式的应用内"一键还原"暂未开放（备份包内为 pg_dump 快照，恢复需停机后用 pg_restore，参考备份页提示）。
- 移动端为自适应布局，暂未做专门优化（P2 后续项）。
- Excel 导入导出字符集为 UTF-8；若用旧版 Excel 打开乱码，请用"数据→自文本导入"选 UTF-8。
