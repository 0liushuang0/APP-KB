# 内网团队版交付计划

目标：一台 Windows 主机运行容器服务，员工电脑经 HTTPS 访问；多人以独立账号协作同一制造项目，数据可备份，关键单据能验收。

1. 修复团队部署配置：强制团队模式、同源 HTTPS 入口、安全密钥初始化、PostgreSQL 备份工具与配置检查。验收：配置可解析，缺密钥/证书时明确失败，客户端 URL 不指向 localhost。
2. 加固制造业务闭环：验证跨客户关联、签约与交付关口、部门评审和并发编辑；补齐失败路径测试。验收：越权及错误关联被拒，业务类型阶段符合预期。
3. 完成交付验证：前后端构建、核心单元测试、独立数据库迁移演练、交付脚本静态与运行检查，记录用户现场必须执行的验收动作。

限制：本开发机未安装 Docker；容器实际启动、客户内网证书信任和多电脑连通性需在部署主机现场验收。未完成这些现场步骤前，不宣称已上线。
